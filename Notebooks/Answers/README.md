# Completed notebook references

This folder contains completed reference versions of the attendee notebooks.
Use them to recover from a blocker, compare an implementation after completing
a goal, or support facilitator demonstrations.

Notebook 2 in the parent folder is intentionally prompt-driven and contains
empty code cells. Its completed implementation is available here.

Notebook 5 is a portal-guided exercise rather than an executable notebook. Its
reference copy preserves the required ontology bindings, relationships, agent
instructions, and evaluation checklist.

The mirror item names remain parameters even in the completed notebooks because
Fabric item names can vary between lab environments.
